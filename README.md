# Finova

Smart personal expense tracking application.

## Features

- User registration and login
- Secure JWT authentication
- Add expenses
- Edit expenses
- Delete expenses
- Expense categories
- Monthly spending
- Total spending
- Recent transactions
- MongoDB database

## Tech Stack

### Frontend
- React
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
